# 資産管理レポート自動生成ツール(ローカルAI版)

CSV/Excelでアップロードした資産(株式・投資信託・債券・現金など)のポートフォリオデータを
集計し、**ローカル環境で動作するLLM**(Ollama)が日本語の総合レポートを自動生成、
PDFとしてダウンロードできるツールです。

クラウドAPIを一切使わず、**すべての処理がローカルPC内で完結**する設計にしています。
金融データを外部に送信できない/したくない環境での利用を想定しています。

📄 **出力サンプル**: [sample_report/asset_report.pdf](sample_report/asset_report.pdf)
(`sample_data/sample_portfolio.csv` を入力に、ELYZA-JP-8Bで生成したレポート例です)

## できること

- CSV/Excelで資産データを一括アップロード
- pandasによる資産クラス別の自動集計(構成比、評価損益上位/下位の抽出)
- ローカルLLM(Ollama)による日本語レポート生成
  - 保有資産の現状サマリー
  - 損益・パフォーマンス分析
  - リバランス提案(一般的な情報提供としてのコメント)
- レポートをPDFとしてダウンロード

## 使用技術

| レイヤー | 技術 |
|---|---|
| フロントエンド/バックエンド | Streamlit |
| データ処理 | pandas |
| ローカルLLM実行基盤 | Ollama |
| PDF生成 | fpdf2 |

## モデル選定について(技術検証の記録)

日本語での出力品質と、非力なCPU環境(GPUなし)での実用速度を両立できるモデルを
選定するため、以下の2モデルを比較検証しました。

検証環境: AMD Ryzen 7 5700U(内蔵GPU / GPUアクセラレーションなし)、RAM 16GB

| モデル | パラメータ数 | 応答速度(体感) | 日本語品質 |
|---|---|---|---|
| Qwen2.5 3B Instruct(Q4_K_M) | 30億 | 約10 字/秒 | やや不自然、誤読漢字あり |
| **Llama-3-ELYZA-JP-8B**(Q4_K_M) | 80億 | 約8 字/秒 | 自然、漢字も正確 |

パラメータ数が3倍近いにも関わらず速度低下はごくわずかだったため、
資産管理レポートという「正確な日本語出力が求められる用途」に適した
**ELYZA-JP-8Bを標準モデルとして採用**しました。

モデルは環境変数で切り替え可能です:

```bash
# 速度優先で軽量モデルに切り替える例
OLLAMA_MODEL=qwen2.5:3b-instruct-q4_K_M python -m streamlit run app.py
```

## セットアップ手順

### 1. Ollamaのインストール

https://ollama.com/download からインストーラーを取得し、インストールします。

### 2. モデルのダウンロード

```bash
# 標準モデル(ELYZA-JP-8B)
ollama pull hf.co/elyza/Llama-3-ELYZA-JP-8B-GGUF:Q4_K_M
ollama cp hf.co/elyza/Llama-3-ELYZA-JP-8B-GGUF:Q4_K_M elyza:8b

# 軽量モデル(任意・速度比較用)
ollama pull qwen2.5:3b-instruct-q4_K_M
```

### 3. 日本語フォントの配置(PDF出力に必要)

IPAexゴシック(無料・商用利用可)を [moji.or.jp/ipafont](https://moji.or.jp/ipafont/) から
ダウンロードし、`ipaexg.ttf` を `fonts/` ディレクトリに配置してください。

### 4. Python依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 5. アプリの起動

```bash
python -m streamlit run app.py
```

`streamlit run app.py`でも動きますが、環境によってはPATHの設定次第で
`streamlit`コマンドが見つからずエラーになることがあるため、
`python -m streamlit run app.py`(pip installと同じPython環境のstreamlitを
確実に呼び出せる書き方)を推奨します。

ブラウザで `http://localhost:8501` が開きます。
`sample_data/sample_portfolio.csv` を使ってすぐに動作確認できます。
実際にどんなレポートが生成されるかは [sample_report/asset_report.pdf](sample_report/asset_report.pdf) を参照してください。

## 他のPCで動かす場合

このアプリはローカル完結型のため、動かすPC側にも以下の環境が必要です(上記セットアップ手順と同じ内容です)。

- Python 3.10以降
- Ollama、および対象モデル(ELYZA-JP-8B, 約5GB)
- `requirements.txt`の依存パッケージ
- IPAexゴシックフォント(PDF出力用)

## クラウドにデプロイしていない理由

このツールはあえてStreamlit Community Cloud等のクラウドにデプロイしていません。
クラウドの無料枠にはGPUがなく、ローカルLLM(Ollama)を動かすためのリソースも
不足しているという技術的制約に加えて、そもそも「金融データを外部のサーバーに
一切送信しない」というこのツールの設計思想そのものが、クラウド上での公開と
相容れないためです。オンプレミス環境でのAI活用を前提とする用途では、
動作するサーバーそのものを社外に置かないことに意味があると考えています。

## 設計上の工夫

- **生データを丸ごとLLMに渡さない**: pandasで先に資産クラス別集計・損益上位/下位の
  抽出まで済ませてから、要約された数値のみをLLMに渡す設計にしています。
  これによりレポート生成の速度と精度の両方を確保しています。
- **オンプレミス完結**: クラウドAPIキーが不要で、ネットワーク接続がなくても
  (モデルダウンロード後は)完全にオフラインで動作します。
- **モデルの差し替えを前提にした設計**: 環境変数一つでモデルサイズ・種類を
  切り替えられるため、将来より高性能なGPU環境が使える場合はより大きなモデルに、
  逆に非力な環境ではより軽量なモデルに、コードを変更せず対応できます。
- **投資助言との線引き**: リバランス提案は「一般的な情報提供」であることを
  プロンプト内で明示し、断定的な投資助言にならないよう配慮しています。
- **日本語組版への対応**: PDF生成ライブラリ(fpdf2)は英語圏向けの改行処理が前提のため、
  そのままでは「禁則処理(句読点が行頭に来ない)」や「英単語・数値を途中で
  分断しない」といった、日本語文書として自然な見た目を実現できません。
  これらに対応する折り返しロジックを独自に実装しています。
  また、LLM出力は同じ内容でも生成のたびに改行の入り方が変わるため、
  見出し・箇条書き以外の改行は「体裁のための改行」とみなして結合してから
  描画する、という前処理も行っています。

## 制限事項

- レポートの生成品質はLLMの出力に依存するため、内容の正確性は都度確認が必要です。
- PDF出力の日本語表示にはUnicode対応フォント(IPAexゴシック等)が別途必要です。
- 大量データ(数百銘柄規模)の場合、要約ロジックの調整が必要になる可能性があります。
- レポート生成には環境によって数分かかります(検証環境: AMD Ryzen 7 5700U、
  GPUなし・CPUのみで約2〜3分)。GPU環境があればより高速に動作します。
